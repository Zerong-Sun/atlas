# 真实地图六维验证与修复清单（2026-08-10）

## 结论

世界地图已从仅绘制的羊皮纸矢量图升级为 OpenStreetMap XYZ 真实瓦片底图，并保留历史路线、城市、海岸、河流、山脉、迷雾和叙事图层。鼠标、触控板和触屏均可连续拖动、缩放；网络不可用时自动回退到本地矢量地图。

## 六维验证

| 维度 | 发现 | 修复与验证 |
|---|---|---|
| 需求完整性 | 运行时配置仍声明等距圆柱投影，且缺少真实瓦片供应方约束 | 配置与同步脚本统一为 Web Mercator；增加瓦片 URL、署名、User-Agent、缓存和并发门禁 |
| 逻辑正确性 | 停靠栏改变地图尺寸后，瓦片会重投影，但城市、道路和地形缓存不会同步 | 投影尺寸变化时统一重建全部投影几何；新增尺寸变化回归测试 |
| 边界情况 | 边缘瓦片可越界覆盖 UI；触屏只能缩放/拖动，不能单指点击城市；双指结束可能误触 | 瓦片按地图矩形裁剪；加入单指点击、双指缩放状态隔离和误触测试 |
| 代码质量 | 缺少协议、缓存寿命、并发、内存和离屏请求约束 | 仅允许 HTTPS XYZ；缓存至少 7 天；并发上限 4；内存缓存有界；只请求当前视口并淘汰离屏队列；署名永久可见 |
| 测试覆盖 | 原测试只覆盖静态矢量图，没有真实瓦片、交互或裁剪验证 | 新增投影、瓦片加载器、鼠标/触控板/触屏交互、边界裁剪与真实场景 smoke 测试 |
| 实际运行 | 缺少完整主场景、窗口渲染、网络瓦片和导出包证据 | 在 1280×720 非 headless 主场景中完成真实瓦片加载与截图级验证；PCK 导出和内容门禁通过 |

## 修复清单

- [x] 使用 Web Mercator 与标准 `{z}/{x}/{y}` XYZ 瓦片坐标。

- [x] 实现鼠标滚轮、拖动、触控板 magnify/pan、触屏单击/拖动/双指缩放。

## 发布注意事项

当前默认使用 OpenStreetMap Foundation 的标准瓦片服务，遵守可见署名、唯一 User-Agent、至少 7 天缓存、禁止批量预取等要求。该服务是尽力而为的公共服务；如进入大规模商业发行，应通过 `content/world/map_tiles.json` 切换到有容量保障的供应方或自托管服务。离线或服务不可达不会阻断游戏，地图会保留本地矢量底图与完整玩法。
