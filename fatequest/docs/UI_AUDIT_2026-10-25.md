## 重现

在 `fatequest/` 目录运行：

```sh
python3 tools/ui/capture_audit.py --phase after
python3 tools/ui/capture_audit.py --phase extras
python3 tools/ui/capture_audit.py --phase gallery
```

脚本自动建立临时项目，保留当前工作区素材，重定向测试存档，并输出截图、几何记录、日志和 HTML 相册。运行需要图形显示环境；`--godot` 可指定引擎路径。当前 `before/` 保留本次修改前的证据，不要在修改后用 `--phase before` 覆盖。
