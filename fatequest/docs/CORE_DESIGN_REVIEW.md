# 《远行之书》核心系统重做与立意审查

更新：2026-08-09

## 结论

本作最有价值的不是“中世纪题材 + 占卜合集”，而是让玩家经历一件更难的事：知识来自具体的人、具体的处境和不完整的转述。系统应奖励求证、建立关系、承认未知和修订游记，而不只是奖励收集与开图。

本轮已经把人物三选一、四年代开局、阶段性死亡警告、终局与传承、24 法目录、8 类学习玩法、跨时代附录以及真实地理地图的基础闭环写进运行时代码。仍不能把占卜系统称为“全部完成”：24 法中 8 法有独立计算引擎，16 法仍使用确定性的通用适配器；部分史源明确标为需要专门史或实践者复核。这个边界必须持续对玩家和制作团队可见。

## 本轮系统裁决

| 系统 | 已落地的规则 | 仍需完成 |
|---|---|---|
| 人物抽取 | 四个历史年代；一次出现三位完整人物；年龄、生辰、起点、命格和执念在确认前可比较 | 将文化、信仰、职业、性别表达拆成可组合维度，避免“职业即文化模板” |
| 死亡与传承 | 健康→吃紧→危重→濒死→死亡；先警告并留救治窗口；死亡是终局；后继者只继承游记、降级地图和一件遗物 | 为疾病、事故、年老分别写临终与悼念文本；补随从见证和地方葬俗的敏感审阅 |
| 占卜 | 24 法一一对应目录、课程、史源、仪式工具和动画方式；8 类可复用小游戏；后世方法只进附录 | 移植剩余 16 个独立算法；给每种方法做路线问题适配；完成史学与实践者复核 |
| 地图 | EPSG:4326 经纬度、真实海岸/河流/海域、1–8 倍缩放和平移、迷雾、经纬网、比例尺、坐标读数；古地图只作为视觉语言 | 加时代化地名与异名；按年代切换港口/路线；为地图情报记录讲述者、时间和可信度 |

## 与“理解世界”相冲突的偏颇

### 1. 旅行者的凝视仍压过当地人的声音

当前 415 个事件中，202 个为演绎、171 个为史源、34 个为混合，另有 8 个没有 `lore.origin`。可识别引用里约 176 个指向 Polo，Battuta 只有约 2 个；这会让欧亚非看起来像被一位外来男性旅行者发现的舞台。

应把“某地是什么”改成“谁在什么处境下这样描述某地”。事件数据应新增：

- `perspective`：商人、朝圣者、船员、妇女、工匠、奴仆、官员、宗教人士等叙述位置；
- `sourceType`：亲历、转述、行政记录、宗教文本、后世整理、游戏演绎；
- `confidence`、`contestedBy`、`localVoice`；
- 同一城市至少一条当地行动者主动设定条件、拒绝或纠正玩家的事件。

### 2. “文化圈”和“宗教”容易被做成属性钥匙

现有 102 城的运行时 `culture` 只有 steppe、east_asia、indian_ocean、islamic 四类；34 城被归为 `islamic`，27 城被归为 `east_asia`。这是生产标签，不足以描述真实社会。若“同宗教成功率更高”直接落成固定加成，会把信仰工具化，也会把跨文化交流写成先天减益。

建议将机制拆成语言、制度身份、礼仪经验、介绍关系、具体社群声望和当下政治风险。信仰可以改变玩家愿意做什么、别人如何理解其承诺，但不应成为统一的开门卡。改宗必须包含长期关系、实践和后果，不能像换装备。

### 3. 角色模板仍把身份天然捆绑

三选一改善了可读性，但原型仍同时携带文化、信仰、职业和起点。玩家会把“某文化的人天然从事某职业”当成系统事实。

下一步应采用分层生成：年代与地点 → 家庭/阶层 → 语言与教育 → 公开信仰与个人实践 → 职业经历 → 旅行执念。组合需由历史可行性约束，而不是固定套装；界面仍展示三位完整人物，不把玩家拖进表格式捏人。

### 4. 占卜仍可能变成权威答案或老虎机

立意写的是“改变理解风险的方式”，但部分占法效果直接 `reveal_map`，容易让仪式凭空产生客观地理知识。通用适配器也会令不同传统只剩不同图标。

每次占卜应输出三层：观察到的符号、导师的解释、玩家可采取的行动。路线情报必须说明它来自谁以及可信度；占卜可标记“值得询问的方向”、改变风险显示或提出备选方案，不应无来源地证明一条路是真的。失败应是误读、信息不足或代价，而不是拿活着的宗教传统做滑稽反馈。

### 5. “理解”仍被收集完成度替代

开图、贴纸、图鉴和占法数量都容易计数，但数量不是理解。当前循环缺少修订、矛盾和承认未知。

游记条目应具有“初闻 → 亲见 → 对照 → 修订”状态。结局评价应记录玩家纠正过多少误解、是否保留相互冲突的说法、是否让当地人的解释进入书中，而不只统计城市和藏品。

### 6. 贸易可能把地方重新写成资源点

若城市的主要差别是商品价格，玩家仍在以提取价值的方式穿越世界。应增加供给背后的劳动、季节、制度和伦理后果；部分地方可拒绝交易，部分利润应伤害关系或加剧短缺。最优路线不能永远等于最高利润路线。

### 7. 性别、阶层与非精英生活没有数据保障

54 位随从中 52 位没有结构化 gender 字段，只有 1 位标记女性、1 位标记男性。没有结构化字段不等于没有文本表现，但意味着项目无法测量谁在说话、谁有行动权。肖像需求文档也已经暴露女性形象明显不足。

不要只补“著名女性”。应覆盖商贩、翻译、医者、旅店经营者、家庭成员、宗教共同体成员和劳动者，并避免把女性仅写成关系对象或受害者。性别字段应允许未知、当地称谓和非现代分类，不强行投射单一现代模型。

### 8. 二百年被压成静态世界

四个开局年代已经解决了入口问题，但城市、政权、路线、疫病、港口和占法可用性仍需真正按年代变化。否则 1253 和 1405 只是不同日期标签。

所有时代敏感记录应逐步增加 `validYears` 或场景覆盖，并建立门禁：历史人物不能越界出现、后世占法不能进入旅程、路线与城市名必须按年代切换。附录可以跨时代，但必须明确它是书外的教学空间。

### 9. 地名和地图也带有叙述权

当前 id 沿用 Polo 异名便于工程对齐，却不能让它成为界面唯一名称。地图应显示玩家当前语言和来源所知的名称，并允许同城保留当地名、旅行者异名和现代识别名。真实底图不是“客观中立”的终点；未知边界、路线精度和名称来源仍应被记录。

### 10. 死亡不应成为耐久度惩罚

死亡系统已经采用可见阶段、救治窗口和不可复活的终局。后续内容必须避免把疾病、衰老和残障统一写成失败减益。治疗可以失败，角色仍可在危重期书写、交代、停留或改变旅程目标；传承的价值是保存有限见证，不是把上一代数值搬给下一代。

## 优先级与验收门槛

### P0：在宣称“内容完整”前

1. 将 16 个通用占法适配器替换为独立、可测试的算法或明确降级为“附录资料，暂不可正式施行”。
2. 为全部占法完成人类专家复核；`review_needed` 不能在发行内容中静默存在。
3. 给所有事件补齐 `lore.origin`，并在玩家界面区分史源、混合与演绎。
4. 为四年代建立城市、人物、路线和事件的年代越界自动门禁。

### P1：让立意真正进入循环

1. 实现游记条目的初闻/亲见/对照/修订。
2. 地图情报记录来源、日期、置信度，错误信息可以被纠正。
3. 角色生成解耦文化、信仰、职业和阶层。
4. 为每个重点城市加入至少一位当地行动者视角与一次玩家被纠正的场景。

### P2：发行前文化与可访问性门禁

1. 宗教与地区敏感读者审阅并记录处理结果。
2. 检查叙述者的地区、性别、阶层和职业分布，不用单一比例替代文本审阅。
3. 所有仪式支持减少动态；重要信息不依赖颜色、动画或声音。
4. 死亡、疾病、改宗和奴役相关内容做单独的语气与伤害审查。

## 一条最终判准

如果某个奖励让玩家更确定“这个地方就是这样”，却没有告诉他是谁说的、何时说的、为何可能说错，那么它偏离了本作立意。好的奖励应让玩家获得更有来历、也更能被修订的理解。
