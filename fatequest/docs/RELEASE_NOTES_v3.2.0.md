# FateQuest v3.2.0 · 剧情探索体验版

这一版把城市中的人和事放回旅程里。103 座城市都接入了新的探索故事；入城、既有地点、后续对话、道路遭遇和结局也经过重写。玩家可以在城里多停留一阵，听店主、船工、家人和同行者把各自的事说完，再决定下一步去哪儿。

## 本版更新

- 103 座城市各新增一处探索故事，并扩写既有入城与地点对话。
- 重写波罗路线的 39 条道路事件、法德兰路线的 35 条道路事件及后续故事；修正部分事件的地点与季节条件。
- 重写两名人物的开场和八种结局，调整故事选项的实际结果与物品、钱币、路线条件。
- 更新中英双语运行文本，补齐新剧情物品的显示名与亚历山大港人物肖像登记。
- 测试改用独立用户数据目录，避免回归测试写入正常游戏存档。

## 下载与验证

- macOS：`FateQuest-v3.2.0-macOS.zip`。
- Windows：`FateQuest-v3.2.0-Windows.zip`，解压后把可执行文件和同目录的 PCK 保留在一起。
- Godot 4.7.1 构建；内容门禁、26 个内核测试模块、56 项冒烟测试通过；5,762 个故事键无缺失或过期，7,069 个运行时双语键完整。
- 图形窗口启动和 1280×720 地图窗口基准通过。详细结果见[验证与修复清单](QA_REPAIR_2026-10-31.md)。

## 已知边界

本版供体验和反馈。逐段人工通读、长时间试玩、肖像及历史文化审阅仍在进行；课程、图鉴正文与界面提示未纳入这轮剧情重写。macOS 和 Windows 构建尚未签名或公证，系统首次打开时可能提示确认。当前机器没有 Linux 导出模板，因此本版没有 Linux 下载包。
