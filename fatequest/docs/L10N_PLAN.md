## 1. 为什么以刺桐为模版

刺桐是唯一**中英双全**的城市，且覆盖了所有文本类型：

| 类型 | 刺桐样例 | key 形态 |
|---|---|---|
| 入城标题 | 刺桐港 | `ev.zayton.entry.title` |
| 入城正文 | （长，待译） | `ev.zayton.entry.body` |
| 选项 | 向大汗的税吏报关 | `ev.zayton.entry.choice.customs` |
| 探索点 | 码头／番坊／天妃宫 | `ev.zayton.harbour.title` |
| 图鉴 | 大汗的什一税 | `codex.cx-zayton-tithe.name` |
| 贴纸 | 如焚林之桅 | `sticker.st-zayton-haven.name` |

**译刺桐时定下的规矩，就是译其余 11 城的规矩。** 先把这一座译到定稿，再横铺。

## 2. 语体规范（沿用 `LORE_PIPELINE.md` §4，此处细化）

英文先导文本摹 Yule 译本的见闻体。中译**不是回译成现代汉语**，而是找到对应的汉语行纪腔。

### 2.1 三条硬规矩

| # | 规矩 | 正 | 误 |
|---|---|---|---|
| 1 | **第二人称见闻体** | 「你须知道，此地……」 | 「玩家可以在这里……」 |
| 2 | **无现代词汇** | 「关税」「牙人」「舶司」 | 「海关」「中介」「进出口」 |
| 3 | **无心理描写** | 「番坊自成一街」 | 「你感到一阵新奇」 |

### 2.2 参照与不照抄

参考冯承钧译《马可波罗行纪》的文言白话腔，**但不照抄**——冯译本 1936 年，版权状态需确认（`LORE_PIPELINE.md` §4 已记）。取其语感，不取其句子。

### 2.3 刺桐实例对照

> **EN**：`The haven of Zayton is frequented by all the ships of India, which bring hither spicery and every kind of costly ware; and you must know that for one shipload of pepper that goes to Alexandria for Christendom, there come a hundred such to this haven.`
>
> **ZH**：「刺桐港者，天竺诸船皆集于此，载香料与百般贵货而来。你须知道：往亚历山大港去、供基督教国用的胡椒，每有一船，来此港者便有百船，且不止百船。」

要点：`you must know that` → 「你须知道」（Yule 的招牌句式，中译须保留）；`Christendom` → 「基督教国」不作「西方」；数字关系照搬不改写。

## 4. 工具与流程

### 4.1 导出待译清单

```bash
node tools/lore/l10n_export.mjs --lang zh --batch B1 > /tmp/b1.tsv
```

产出 TSV：`key ⇥ english ⇥ zh_existing ⇥ context`。**`context` 列必须有**——译者需要知道这句话出现在哪座城、哪个选项下，否则「Ask the pilots」译不准。

### 4.2 回填

```bash
node tools/lore/l10n_import.mjs --lang zh /tmp/b1.done.tsv
```

**只写 `zh.json`，不碰 `en.json`**；已有译文不覆盖（除非带 `--force`）。

### 4.3 质量门禁

| 门禁 | 检查 | 状态 |
|---|---|---|
| **G7** | 译名与 `glossary.json` 一致 | ⛔ **待实现，B1 开译前必须有** |
| G17 | 未译条目计数与覆盖率 | 建议加，让进度每次 CI 可见 |
| G18 | 中文正文不得含 ASCII 长句 | 防止漏译混入 |

**G7 是最关键的一条**：38 条地名 + 57 条术语必须全局一致。Zayton 一会儿「刺桐」一会儿「泉州」，玩家会以为是两个地方。

## 5. 运行时行为（已实现）

`core/i18n/i18n.gd` 的回退链已就位：

```
请求语言 → 英文 → key 本身
```

- 中文缺失时**显示英文原文**，不显示裸 key
- 界面标注「(尚未译出，暂显英文原文)」，玩家知道这是待补而非 bug
- `I18n.untranslated_keys()` 可在运行时统计待译量
- `I18n.fmt()` 处理带参数 key（`explain.need_language:chinese` → 「需通晓：汉语」）

**这意味着中译可以增量交付**，不必等全译完才能玩中文版。

## 6. 机器翻译的边界

`LORE_PIPELINE.md` §4 写「不要机器全量翻译」。细化为：

| 允许 | 不允许 |
|---|---|
| 用机翻做**初稿**，人工逐条校订 | 机翻直接入库 |
| 短串（选项、贴纸名）机翻 + 抽检 | 长正文机翻不校 |
| 术语按 glossary 强制替换 | 让机翻自由决定译名 |

**长正文（194 条）必须人工**。见闻体的语感是这部作品的价值所在，机翻会把「你须知道」变成「您需要知道的是」。
