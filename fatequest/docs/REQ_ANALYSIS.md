### 1.2 核心问题

| 问题 | 具体表现 |
|------|----------|
| **没有角色抽取** | 直接进旅程，无身份背景代入 |
| **地图不可交互** | 纯贴图展示，不能点击城市、不能查看详情 |
| **城市无探索感** | 四键即走，没有选项分支、无对话树 |

| **地图无动态解锁** | 开局全图可见，非"地图来自询问" |
| **无出行动画** | 节点瞬移，无"在路上"的感觉 |

## 2. 游戏主流程

### 2.1 完整流程

```
开场书案
  → 角色抽取（生辰+命格+身份+起点城市）
  → 进入起点城市
  → 城市探索（对话/探索点/市集/庙宇）
  → NPC对话获得路线情报
  → 地图解锁新城市/路线
  → 选择出行方式 → 确认出发 → 出行动画
  → 途中遭遇事件
  → 到达下一城市
  → （循环）
```

### 2.2 角色抽取系统

**定位**：开场第一个可操作系统，不是一次性表单，而是有仪式感的抽取过程。

**流程**：

1. **书案画面**：中世纪旅行书叠于羊皮纸地图上，可翻阅。点击「开始远行」。
2. **过场加载**：贴图循环 + 箴言（港口/沙漠/驿站/寺院…共11张）
3. **生辰抽取**：1253-1453年间随机一天，显示公历+农历+时代背景。可重抽3次。
4. **命理测算**：自动生成三条命运条（远行运/交涉运/财货运，0-31点），显示九等评级（上上…下下）。
5. **身份确认**：
   - 文化背景 → 决定起点城市候选池
   - 宗教身份 → 决定初始占卜法权
   - 旅行执念 → 软主线方向
6. **起点城市确定**：从身份匹配的城市池中展示可选城市（初始2-3座，取决于文化圈），玩家选择一座作为起点。

**数据依赖**：
- 城市表 `cities.json`（已设计，待填写12条）
- 角色表 `archetypes.json`（已设计，待填写3条）
- 生辰/命运系统（引擎已有雏形）

### 2.3 城市探索系统

**每城固定结构**（GDD §6）：

```
城市入口事件
  ├── 探索点1（含故事+图鉴+物品/情报）
  ├── 探索点2
  ├── 探索点3
  ├── 市集（买卖商品）
  ├── 信仰场所（祈福/改宗）
  ├── 导师（学占卜/语言/礼仪）
  └── 路线出口（通向下一城市）
```

**核心交互**：每个探索点是一个多选项事件，选项触发：
- 不同对话分支
- 地图解锁（新城市/新路线出现）
- 线索获得（用于断案或解锁隐藏路线）
- 物品获得（商品/信物/占具）
- 声望变化（分地区计算）

**选项设计原则**：
- 至少有一个占卜选项（高方差，可能解锁隐藏分支）
- 至少有一个确定选项（小收益/小代价）
- 特殊选项需要前置条件（语言/物品/随从/声望）

## 4. 地图系统

### 4.1 当前问题

`map.js` 实现了精美的SVG手绘地图，但：
- 城市仅为静态符号，不可点击
- 无城市详情弹窗
- 路线全部可见，无"地图来自询问"的渐进解锁
- 无迷雾/未探索区遮蔽
- 仅有粗粒度区域多边形（4个文明区），无精确城市坐标

### 4.2 目标设计

**地图交互层**：
1. **可点击城市**：每个城市独立的SVG `<g>` 可点击，点击后弹出城市信息卡：
   - 城市名（中/英）
   - 中世纪称谓
   - 所属文化/宗教
   - 简介（100-200字，来源游记）
   - 已知景点列表
   - 已知出口路线
   - 当前可用的出行方式

2. **动态解锁**：
   - 开局：仅起点城市 + 文化圈内1-2座知名城市可见
   - 解锁途径：NPC对话、阅读游记、购买地图碎片、完成探索点
   - 未解锁城市：地图上显示为云雾遮蔽区
   - 已解锁不可通行：城市显示但路线为虚线（需道路信息）
   - 已解锁可通行：城市+路线均为实线

3. **迷雾层**：canvas渲染，已探索区轻霭0.25，未探索区浓雾0.85。解锁时雾旋涡状散开。

4. **出行触发**：
   - 在城市详情卡中选择出行方式
   - 出行方式取决于：城市出口、玩家携带物品（驿马需金牌信物）、季节/天气
   - 确认后开始出行动画 + 途中遭遇

### 4.3 地图数据

已有 `fatequest-worldmap/` 包的90城市坐标、21山脉、23河流，可直接导入。

城市坐标绑定到 `cities.json` 的 `coord` [lng, lat] 字段，通过仿射投影转视图坐标。

## 6. 占卜学习系统

### 6.1 当前问题

- 点击"学习"后立即学会，无任何过程
- 学习后无法实际使用（未接入游戏主流程）
- 无操作手感

### 6.2 目标设计

**学习 = 拜师 + 通过小游戏考核**

每种占法配一个5-15秒的微操小游戏：

| 占法 | 学习地点 | 导师 | 小游戏 | 操作 | 判定 |
|------|----------|------|--------|------|------|
| 塔罗 | 威尼斯/大不里士 | 帖必烈 | 切牌手感 | 拖拽切一叠牌 | 匀速完成 |
| 易经（铜钱卦） | 泉州/杭州 | 陈婆 | 三连节拍 | 按节奏点三下（渐快） | 全中节拍窗口 |
| 梅花心易 | 大都 | 某道士 | 心算起卦 | 报数窗口内心算加和 | 答对卦数 |
| 八字 | 大都/杭州 | 某命师 | 排盘拼图 | 拖拽干支到正确位置 | 正确排列 |
| 西洋占星 | 君士坦丁堡/大不里士 | 某修士/星家 | 星盘对准 | 转动三环对齐星位 | 三环误差<5° |
| 卢恩符文 | 北欧/草原地区 | 某萨满 | 摸符 | 袋中拖拽晃动，倾斜倒出 | 三枚同屏落定 |
| 掷筊 | 泉州 | 林三娘 | 蓄力抛掷 | 长按蓄力，松手定弧线 | 落点入香案圆心 |
| 星辰骰 | 大不里士/开罗 | 帖必烈 | 骰子投掷 | 摇动后投出 | 点数组合 |
| 梦占 | 伊斯兰/基督教城市 | 某修士 | 梦境选择 | 从碎片画面拼出完整梦境 | 选择正确碎片 |
| 签诗 | 中国寺庙 | 某庙祝 | 摇签筒 | 摇晃手机/点击节奏 | 一支跳出 |

**学习流程**：
1. 到达可学习城市
2. 访问导师（触发导师对话事件）
3. 导师介绍占法（一段叙事文本）
4. 进入小游戏（可设置关闭，关闭后自动通过）
5. 通过后：学会该占法 + 获得该占法的占具 + 图鉴解锁
6. 未通过：可重试（消耗金币），或继续旅行后回来再学

**使用流程**：
1. 在事件选项中选择"以[占法]应对"
2. 进入占卜仪式界面
3. 执行该占法的操作（与学习时相同的小游戏，仪式分影响效果但不影响概率）
4. 揭示结果：得到路线建议/风险预测/对话线索
5. 结果影响实际游戏状态（路线风险降低、新路线揭示等）

## 7. 存档管理

### 7.1 设计

- **自动存档**：每次到达新城市、完成探索点、通过占卜、招募随从时自动保存
- **手动存档**：提供3个存档槽
- **存档内容**：
  - 角色信息（姓名/生辰/命格/身份/执念）
  - 当前位置（城市/节点）
  - 已解锁地图（城市+路线）
  - 背包（商品/占具/信物）
  - 声望表（分地区）
  - 语言/礼仪能力
  - 已学占法
  - 随从及好感
  - 图鉴/贴纸/结语标记
  - 天数/盘缠/星尘/等级
- **存储方式**：localStorage（现有 `state.js` 已有基础）

### 7.2 实现

扩展现有 `state.js`：
- `FQ.save(slot)` — 序列化全量状态
- `FQ.load(slot)` — 恢复状态
- `FQ.listSaves()` — 返回存档列表（含时间戳/位置/天数摘要）
- 存档界面：在"记录"tab下展示
