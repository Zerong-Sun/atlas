## 2. P1 · 美术接线（ZERO 新图）

### 2.1 起点

```
assets/art/*.webp   600 张（全部已 Godot-import）
  runtime 接线       57  （map_art.gd 动态模式）
  未接线            543
```

**接线不是换图、不是重绘、不是调色——是把文件路径告诉代码让它去加载。**

### 2.2 按前缀分批

| 前缀 | 数量 | 接线落点 | 优先级 |
|---|---|---|---|
| `explore-*` | 36 | 十二主城探索点背景 | ⭐⭐⭐ |
| `site-*` | 22 + 2 new | 7 城探索大图 | ⭐⭐⭐ |
| `npc-*` | 52 | 城市探索立绘（16 已接） | ⭐⭐ |
| `ic-*` | 143 | 市集 + 图鉴图标 | ⭐⭐ |
| `sym-*` | 42 | 占卜符号 | ⭐⭐ |
| `ui-*` | 62 | 界面装饰 | ⭐ |
| `map-*` | 26 | 地图饰件（28 已接） | ⭐ |
| 其余 | 160 | 入城/过场/导师/书封/交通 | ⭐ |

### 2.3 接线方式

所有接线走 `MapArt` 单一入口（`game/map/map_art.gd`）：

- 地图饰件：`map_art.gd` 的 `CITY_ICON` / `TERRAIN` 映射表
- 探索点背景：`city_view.gd` 的 site→texture 映射
- 商品图标：`GOODS_ART_MAP.json`（good_id → texture path）
- NPC 立绘：`city_view.gd` 的 npc→texture 映射
- 占卜符号：`divination_*.gd` 的 sym→texture 映射
- UI 装饰：各 `.tscn` 的 `TextureRect`

**原则**：纹理缺失时回退到纯色/文字，不崩溃。

### 2.4 验收

- [ ] `explore-*` + `site-*` 全部接线——探索点不再是纯色底板
- [ ] `npc-*` 接线 36+——城市探索立绘丰富
- [ ] `ic-*` 接线至 `GOODS_ART_MAP.json`，市集图标可用
- [ ] 验证：游走一条线，各城探索画面不为纯色底板
