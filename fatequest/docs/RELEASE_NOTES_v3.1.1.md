# FateQuest v3.1.1 · Windows / macOS 发布说明

本版本在 v3.1.0 的流程、测试和开场音乐基础上，补齐 Windows 与 macOS 可下载构建。

## 下载

- `FateQuest-v3.1.1-macOS.zip`：macOS 发行包。
- `FateQuest-v3.1.1-Windows.zip`：Windows 发行包，包含可执行文件和配套 PCK。

## 验证

- Godot 4.7.1 发行模板：Windows x86_64、macOS。
- 内容门禁：`all gates pass`。
- 游戏契约测试：1,467 条记录、1,074 个事件选项、103 座城市、206 条路线，0 失败。
- PCK 结构验证：通过。
- 真实窗口地图和音频冒烟：通过。
