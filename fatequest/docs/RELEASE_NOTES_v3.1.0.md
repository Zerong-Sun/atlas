# FateQuest v3.1.0 · 发布说明

本版本把可玩旅程的验收标准落成可重复的 Godot 检查，并补齐开局到城市音乐的入口体验。

## 本版本内容

- 建立六维游戏测试标准：需求完整性、逻辑正确性、边界情况、代码质量、覆盖率和实际运行结果。
- 新增运行时流程契约，覆盖 1,467 条内容记录、1,074 个事件选项、103 座城市和 206 条路线，检查每个选择都有反馈或后续、每座城市都有出口。
- 修复欢迎旅程测试的 `ui.cfg` 隔离问题，避免测试之间污染玩家偏好。
- 新增独立开场主题 `assets/audio/intro/title_theme.wav`；书桌启动时播放，开始旅程或读档时淡出，再交给文化与场景音乐层。
- 网络地图探针改为图形/网络 opt-in；离线 headless 回归不会把 CDN 不可用误报为玩法失败。

## 验证结果

- 内容验证：`all gates pass`
- 核心 Godot 测试：`SUITE: PASS`
- Headless smoke：46 个测试，0 个失败
- 真实窗口地图探针：12 张瓦片、归属标识、输入层和 1280×720 画面通过
- 真实窗口音频冒烟：通过
