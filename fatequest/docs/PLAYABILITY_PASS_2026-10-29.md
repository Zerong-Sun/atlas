# 可玩性短循环整改 · 2026-10-29

## 找到的问题

游戏已有旅行、城市事件、市场、占法和结局，但角色的 `goal` 只出现在人物数据里；进入城市后，玩家没有一个随行动变化的近程目标。道路列表虽然可用，却缺少与当前故事相连的下一步。事件选择也只显示行动文字，数据里确定会扣除的银钱和天数要在结算后才看见。这让玩家难以计划，也削弱了选择的重量。

内容层还有更大的后续问题：当前 493 个事件的选项中，150 个选项只有 `reveal_map` 一种效果。这些分支即使配有不同文案，长期后果也可能很像。本次先修玩家在首段旅程中立即能感到的方向与决策信息，不把界面提示当成全部内容改写。

## 已做

- 城市上方显示角色远行心愿，以及当前可执行的一步。新到一城先推荐真实可触发的景点；完成后推荐可支付且可通行的新城。若道路暂时不可走，提示查看条件并准备。目标由现有世界状态计算，存读档无需新增任务字段。
- 道路面板显示简短下一步，并把推荐的新城路线放在前面。城市景点、市场和其他道路仍可自由选择。
- 事件按钮显示数据里确定的即时银钱与时间代价；奖励和后续分支仍由故事揭示。
- 新增中英界面文案与引导逻辑测试，扩充事件对话框的代价测试。
- 音频测试仍按旧版“神龛静音旋律、紧张时完全去掉旋律”断言，和工作区已经采用的轻旋律方案冲突；将断言改为检查神龛及紧张场景的旋律确实比普通城镇更轻，同时保留旋律。

## 第二轮：选择、出路与内容门禁

- 全部九种出身逐一验证目标文案；`network` 类目标不会仅因到达目标城就声称完成。草原旅人原本没有任何已知出城路，现可从大不里士前往报达；抵达后自动知道报达的出口。
- 38 个原本多花一天却没有额外收益的入城选项，改为休息恢复体力或问路得到真实路线。41 个写着购买却免费得货的选项现在扣费；资金门槛与费用一致。原有 23 个扣费但缺门槛的选项也已修正，免费直接通过分支仍可选。
- 城市界面对重复的同一景点 ID 去重；城市和道路面板均不会把同一个景点显示两次。第三轮又为这 17 城补了独立的第二景点，数据表不再依靠重复 ID 占位。
- 补齐 61 个地点场景的 366 条英文文本和 8 张双语图鉴；逐段校对中英文地名与场景，修复翻译指纹和动态 UI 键误报。内容门禁现已全部通过。
- 角色短程指引按目标城市的可达路径推荐道路；季节关闭的目标路线不会被更远的绕路遮盖。
