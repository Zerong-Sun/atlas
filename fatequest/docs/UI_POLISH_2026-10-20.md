## 验证方法

Godot 4.7.1；所有 UI 测试使用 `tools/validate/playtest_local.py` 的独立存档与偏好目录，不覆盖玩家进度。此次同时修正测试目录在 macOS 下的实际路径和自动清理，并保留超时前的完整日志。

新增的五项 UI 回归、已扩展的开局回归已接入 CI：

- `smoke_button_motion`：通用交互反馈、重入动画与焦点。
- `smoke_portrait_mapping`：图像对应、稳定性与缺图处理。
- `smoke_hire_contract`：窄窗合同与同步单次确认。
- `smoke_dialog_usability`：长选项、键盘、重复提交与偏好保存。
- `smoke_city_market_usability`：布局、交易、语言切换、焦点及设置入口。
- `smoke_character_draw`：开局响应式布局及角色确认。

同时回归启动、玩家操作面、欢迎线、白图泰线、整体流程、途中续玩、市场、同行、书页、面板拖动及城市导航。市场交易审计和静态内容门禁通过；3943 条叙事译文均为 current，0 stale、0 missing。

真实窗口已完成欢迎线、城市／市集和开局的测试与截图。测试期间普通有声进程停在系统音频初始化；
macOS `sample` 显示主线程位于 CoreAudio → AppleHDAHALPlugIn → IOServiceOpen。
切换 `--audio-driver Dummy` 后同一游戏流程正常运行，因此实窗画面验收使用无声模式，未验收音频播放。
保留正常启动入口，另提供 `Play FateQuest (Silent).command`，不修改系统音频设置。

画面记录在 `build/playtest/`：`welcome-gate.png`、`alexandria-market.png`、
`city-polish-large-en.png`、`market-polish-narrow-zh.png`、`character-draw-large-zh.png`。

`smoke_save` 的故意损坏存档用例返回 `SAVE: OK`，并按设计输出拒绝覆盖坏存档的错误日志；严格 UI runner 会将这条预期错误标为失败，它不属于此次新增的零错误 UI 测试。

## 还没有制作完成的内容

本轮修复了已确认的图像错配，但没有为每个命名角色绘制专属画像。现有多人素材拆分、女性及草原／印度洋等角色补图、按城市逐一审美复核仍属于后续素材制作；未审核图片不会再被强行填到人物位置上。

剧情完整性、舞蹈与表演介绍、更多城市的书源拆分继续按 [剧情与可玩性整改清单](PLAYABILITY_REBUILD_2026-10-20.md) 推进。这一轮的界面回归不能替代所有剧情分支与所有屏幕尺寸的人工验收。

## 建议试玩顺序

双击根目录 `Play FateQuest.command`。先缩小窗口、切换大字号并抽取身份，再从城市进入事件、市集和雇佣；检查每次选择后能继续、能退出。剧情页可用 Tab／Shift-Tab、Enter 和 Esc；城市底栏进入设置，可切换语言、字号、高对比和减少动效。
如果本机在启动时卡在音频设备初始化，使用 `Play FateQuest (Silent).command` 无声试玩。
