# 东亚叙事细节扩写记录（2026-10-26）

本批在 15 个城市的玩家可读场景中各补入一处可复述的历史/地理/工艺信息。创作底本主要是《马可·波罗游记》Henry Yule 英译、校注本（1871）；它保存了旅行记叙述，也有后世校注。凡属游记作者转述、夸张数字或史料争议，正文以“记载/据说/旧账”呈现，不冒充无争议的现场实录。对路线辨认有争论的通州（Tanpiju）仅补充原文本身给出的行程和景观，不将其历史定位写成定论。

## 分城记录

| 城市 / 中文文本 | 玩家能学到的具体信息 | 依据与来源 |
|---|---|---|
| 刺桐（zayton） | 印度货在刺桐卸下后，可由当地船只沿闽江转运至福州；海运与内河转运相接。 | Polo, *Travels*, vol. II, ch. LXXXI：印度船到刺桐，货物再由船沿闽江送往福州。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) |
| 福州（fuju） | 城中造船并下水入闽江；印度货由刺桐海港换船上溯。另有蔗汁煮制与树灰精炼的糖工艺传说。 | 同上 ch. LXXXI；该章称福州造船、产大量糖，Yule 注释引述“原先煮蔗汁得黑膏，后由巴比伦人教用特定树灰精炼”的旅行记版本。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) |
| 哈密（camul） | 绿洲果园以蓄水/灌溉维持；鲜瓜就近出售，葡萄可晒成果干供商队携带。 | Polo, vol. I, ch. XLI 记两片沙漠间的 Camul 物产充足；Yule 对应注释将其识别为 Hami 绿洲，记灌溉蓄水及瓜果、葡萄干产出。[Project Gutenberg, vol. I](https://www.gutenberg.org/files/10636/10636-h/10636-h.htm)  注：灌溉与葡萄干依据为校注/历史地理旁证，不是正文旅人亲述。 |
| 汗八里（cambaluc） | 帝国官道驿站通常间隔约 25–30 英里；信使可在驿站换马、住宿、接力送公文，荒路间距会更长。 | Polo, vol. I, ch. XCV 详述驿站、换马及 25–30 英里间隔。[Project Gutenberg, vol. I](https://www.gutenberg.org/files/10636/10636-h/10636-h.htm) 正文“驿站认可的凭信”承接已有游戏设定，不另增玩法。 |
| 镇江府（chinghianfu） | 1278 年，景教徒马儿撒儿吉思奉命出任三年地方长官；任内建两座景教堂。 | Polo, vol. II, ch. LXXIII。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) |
| 襄阳府（saianfu） | 城池三面临水、北面是易接近的陆路；旅行记称抛石机发射约 300 磅石弹。 | Polo, vol. II, ch. LXX；Yule 注释明确指出该围城叙述有版本差异，相关战事解释存在争议，故游戏文本标为“据《行纪》记载”，不当作无争议史实。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) |
| 通州（tanpiju） | 从行在（杭州）东南行一天抵达；后续路线上城镇、村庄与园林相连，旅行记再给出三天、两天的分段距离。 | Polo, vol. II, ch. LXXIX；同章 Yule 注释指出 Tanpiju 的具体定位有争论，故正文只写路线记载，不将地名考证写死。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) |
| 河间府（cacanfu） | 大河由支渠、运河连接汗八里，丝织品可利用水网运至都城。 | Polo, vol. II, ch. LX 记河间府所在区域有大河，经多条水道连接汗八里、货运繁忙。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) |
| 河中府（cachanfu） | 河边可见粗大竹材；当地船工把竹竿劈成篾条并拧成拖船缆绳，逆流时由岸上牵引。 | Polo, vol. II, ch. LX（河中府段落及河岸竹材）；同卷 ch. LXXI 具体记强流中上行船需岸上拖曳，约 300 步长的缆绳以劈细、拧股的竹篾制成。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) |
| 陵州（linju） | 河上船只数量很多，承担贵重货物运输；城市贸易与水路相连。 | Polo, vol. II, ch. LXIII 记陵州位于河边，船只比此前所见更多并运输大量贵重货物。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) |
| 邳州（siju） | 南行三天可到宽阔且深到能走大船的河；旅行记称河上有大批官船，兼用于运送士兵、马匹与军需。 | Polo, vol. II, ch. LXIV 描写 Siju 后三天到 Caramoran，并给出官船、船员与运载马匹的记载。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) 注：数字为旅行记记载。 |
| 长芦（chinangli） | 旅行记称商人买卖货物都缴关税；故事让玩家看到账房将货价、数量、应税额分开记账的实际用途。 | Polo, vol. II, ch. LXIX 记当地丝绸与贸易、商人财富及朝廷从货物买卖中征收关税。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) 账目栏目的具体呈现是为可读性所作的场景化表达。 |
| 安庆（nanghin，编注暂定） | 丝绸与金线织物、低价粮食及交易关税共同构成当地贸易；商人要把进货、转售、税金合并核算。 | Polo, vol. II, ch. LXIX 记丝金织物、廉价粮食、富商及交易税收。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) 账房对话为史料事实的场景化，不添加未经来源支持的织造技术。 |
| 髣城（pein） | 旅行记记此地河流产碧玉（jasper）和玉髓（chalcedony）；买石时应问清石种与产地，避免把不同矿物都当同一种“玉”。 | Polo, vol. I, ch. XXXVII 直接记河中产 jasper 与 chalcedony；Yule 注释讨论其与本地“玉”贸易的对应关系。[Project Gutenberg, vol. I](https://www.gutenberg.org/files/10636/10636-h/10636-h.htm) 对话不教授未经史料支持的肉眼鉴定诀窍。 |
| 瓜州（caiju） | 朝廷粮米在此集散，运河把河流、湖泊接成大船可行的深水线；挖出的土堆成堤路，水运与陆路并用。 | Polo, vol. II, ch. LXXII；Yule 注释引述 Rashiduddin 对运河开凿、堤岸石护及沿线陆路的描述，并补充元代漕运统计。[Project Gutenberg, vol. II](https://www.gutenberg.org/files/12410/12410-h/12410-h.htm) |

## 改写原则

- 把知识放进玩家正在做的事：看货、问路、算账、等船或听地方人讲旧事。
- 给出可以复述的步骤、尺度、路线关系或判断问题；避免“当地人告诉你风土人情”之类的空句。
- 将游记作者的说法、后世校注和有争议的定位区分开；不把校注材料假装成角色亲见。
- 保持原有剧情 key、选项、结果和玩法效果不变；本批仅扩写现有 story 文本。
