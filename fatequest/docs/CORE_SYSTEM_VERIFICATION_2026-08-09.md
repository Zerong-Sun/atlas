# 核心系统六维验证与修复清单

日期：2026-08-09
范围：人物抽取、死亡与传承、占卜目录/课程/附录、真实地理地图、存档与主流程接线。

## 总结

本轮从需求完整性、逻辑正确性、边界情况、代码质量、测试覆盖、实际运行结果六个维度完成验证。共确认 15 项可修复问题，已全部修复并增加自动回归；内容门禁 G1–G33、21 项核心测试、30 条界面 smoke 和主场景实际启动均通过。

仍有三项明确的内容生产边界，不作为“已完成”隐藏：16 种占法当前是资料适配器而非独立算法；部分占法来源仍需要学者/实践者复核；四年代尚未让全部城市、人物、路线和事件发生动态变化。它们保留在 `CORE_DESIGN_REVIEW.md` 的发行前清单中。
