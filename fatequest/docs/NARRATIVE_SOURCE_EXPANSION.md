# 城市叙事补充史料：中世纪人的世界观与日常谈资

这份清单服务于 103 城的中文剧情重写。目标不是再给 NPC 塞一段“当地简介”，而是找当时人写过、抄过、画过什么，再把合适的细节放进他们正在做的事：商人议价时拿本地货夸口，旅人争论哪条路更远，书记在地图边上解释自己听来的世界，港口人看风向改口谈船期。

## 写进对白的方式

- 不让人物说“本城有 X、Y、Z 三个特点”。让细节解决手边的问题：客人问价，商人展示织纹并说自家货为何值钱；旅人问路，车夫顺口比较哪口井能饮、哪一段风会误船期。
- 地理知识通过人物立场出现。制图师可以强调自己地图的方向和边界，海员只相信眼前风向，朝圣者按圣地和驿站记路，商人用货源与税关定位；不同角色可以互相纠正。
- 奇闻要有来源关系：“我在某书里读到”“上一队商人这么讲”“我亲眼见的是……”三者不可混为一谈。可让 NPC 卖弄、夸大或出错，旁白不要替错误观点盖章。
- 取用真实细节时优先保留动作、物件、称呼和判断逻辑，避免照搬译文长句。玩家能从情境理解风土，不需要 NPC 宣告“现在开始介绍当地风俗”。
- 一段对话最多承担一个主要信息和一个人物目的。若把文化说明拿掉后，交易、问路、争执或关系场景仍成立，说明风土细节已经嵌进去；若整段只剩“讲知识”，改写成实际行动。
