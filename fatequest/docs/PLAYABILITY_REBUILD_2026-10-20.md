# FateQuest 剧情与可玩性整改清单

本轮以玩家提出的《八十天环游世界》式旅行体验为目标：抽到身份后，能在具体城市遇到具体的人，作出选择，看到后果，了解当地生活、购买商品，再决定留下还是前往下一站。先保证流程走得通，再把书里的细节变成可玩的经历。

## 当前问题与完成标准

## 目标玩法

开局选择年代并抽取人物，明确显示身份、语言、信仰、起点、盘缠和旅行愿望。身份提供不同交往机会，不能决定所有当地人必然如何对待玩家。

进入城市后，先读一小段能建立地点感的文字，再选择求助、观察、问路或直接进城。缺钱时应有可理解的生存出口，不能只有付费选项。陌生人的接待可以带来饭食、关系和路线消息；是否接受、是否透露困境、是否回访，由玩家决定。

城市至少有接待或住宿、集市、生活风俗、旅行消息四种活动。读到商品后应能找到真实买卖入口；读到道路后应能在出发页找到该路线。每个故事结束都回到可行动的城市，而不是消失在日志里。

离城时显示目的地、方式、预计天数、费用和条件。取消后回城；路上事件结束后继续旅途；抵达后开启新的城市生活。旅行不是必须按固定剧情顺序点击，玩家可以跳过演出、拒绝购买或提前离开。

## 白图泰线的第一段样板

现有身份从亚历山大港开始，先利用已有地图、市集和道路做出可测试的段落。城门落泪的具体故事仍需补充对应版本；当前本地 Samuel Lee 1829 节译本第一章包含的是一位贫寒学者在亚历山大港等候吉兆、被守门人称作法官的故事，不能把这段标成白图泰本人在突尼斯哭泣。

| 场景 | 玩家行动 | 可见后果与去向 |
|---|---|---|
| 城门 | 穆斯林旅人说明来意；缺钱时承认困顿或落泪；任何人均可直接进城 | 接待支线或城市自由探索；困顿剧情明确标为创作 |
| 一席饭 | 接受援助并问路；只接受饭食；婉谢 | 一次性援助或关系变化、开罗道路消息；每项都有后果页 |
| 城市 | 看现有见闻、逛市集、查看行囊、选择出发 | 市集使用实际库存与价格；购买后钱和行囊同步变化 |
| 离城 | 选择开罗等可达城市与交通方式，确认或取消 | 确认进入旅途；取消回到可操作界面；中途事件和读档可续 |
| 后续扩写 | 有出处的宴饮、演出、工艺和饰品 | 本轮不以通用“异域歌舞”填空；逐城核实后再接入 |

## 书籍拆解要求

每条见闻卡包含：书与版本、原文文件、章节及段落锚点、地点与年代、参与者、具体物件或风俗、原文事实、游戏演绎、触发条件、至少两种行动、即时后果、后续标记或路线、对应事件、测试状态。一个章节可拆多条见闻，跨城章节必须按实际叙事地点拆开。

| 书 | 当前本地素材 | 下一步 |
|---|---|---|
| 马可·波罗 | 136 地点、98 故事 | 优先挑选可与白图泰路线交汇的城市，补货物与场景，不批量复制城市模板 |
| 伊本·白图泰 | 46 地点、18 故事 | 先修第一章地点与人物错配；补城门、接待、人际网络及市场见闻 |
| 伊本·法德兰 | 32 地点、34 故事 | 区分十世纪记述与游戏时代的历史阅读，核对草原事件的使用方式 |
| 伊本·朱拜尔 | 21 地点、15 故事 | 优先接待、旅行设施与交通；旧状态页的计数需要更正 |
| 瀛涯胜览 | 18 地点、1 故事 | 按港口拆物产、贸易、饮食和礼俗；不能把一个地方介绍当整城剧情 |
| 平托远游记 | 5 地点、8 故事 | 保持十六世纪书案阅读属性，不能直接变成中世纪城市证据 |
| 鲁布鲁克等选段 | 书案选段与补充引文 | 标为选段库，逐条建立可玩性状态，不称整本拆解完成 |

## 执行顺序

1. 安装 Godot，保留首次启动失败证据，完成干净环境回归。
2. 修复启动、事件继续和后果队列；先确保读完选择能回到可行动状态。
3. 修白图泰错误来源与第一章地点串段，建立首批见闻卡。
4. 接入亚历山大港困顿与接待样板，验证零钱、拒绝、不同身份、暂停和重进。
5. 跑实际市集交易、出发及恢复流程，记录尚未覆盖的人工体验项。
6. 扩写有出处的表演与饰品，再沿开罗及后续城市逐站推进。全城剧情重写不以本轮样板完成代替。

### 本机测试方法

双击项目里的 `Play FateQuest.command` 可启动游戏；编辑器打开 `project.godot` 后按 F5。抽到白图泰旅人身份后，从亚历山大港入城选择“打听哪里接待外乡旅人”，或在城内选择“城门下的陌生人”。盘缠不高于二十银时可选落泪求助；获得十二银后可在市集购买玻璃珠，再从“上路”选择开罗。

在 `fatequest` 目录运行：

```bash
python3 tools/validate/playtest_local.py tests/smoke_welcome_journey.gd
python3 tools/validate/playtest_local.py --windowed tests/smoke_welcome_journey.gd
python3 tools/lore/audit_reading_cards.py
node tools/validate/validate.mjs
node tools/lore/story.mjs check
```

界面回归使用临时偏好及存档目录，日志写到 `build/playtest/`。窗口回归截图为 `welcome-gate.png` 与 `alexandria-market.png`。见闻卡保存在 `assets/books/reading_cards.json`，其章节锚点和事件引用由上面的核验脚本检查。
