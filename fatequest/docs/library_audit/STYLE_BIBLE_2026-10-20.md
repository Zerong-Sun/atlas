# FateQuest 统一风格与生产 Prompt

这是资料库整改后的共同基线。它约束新的文字、图片、音乐和音效，避免每一条线各自变得漂亮，却拼在一起不像同一款游戏。风格服从历史语境、角色身份和实际玩法；风格统一不等于把所有城市做成同一种颜色、同一种口音或同一套乐器。

## 共同体验

FateQuest 的核心不是“参观景点”，而是一个处境中的人抵达陌生城市，靠礼貌、观察、交易和聆听换取下一步路。每个素材都应回答三个问题：玩家现在在哪里？谁正在与玩家发生关系？这个选择会打开哪条路？素材应留下一个可行动的线索，而不是只提供装饰。

统一的关键词是：旅途中的温度、可辨认的地方性、克制的神秘感、纸张与尘土的触感、选择之后留下痕迹。禁止把文化差异压缩成“异域”“神秘”“热闹”三个空泛标签，也禁止把宗教场所做成滑稽的失败奖励。

## 文本 Prompt

```text
你是 FateQuest 的叙事编辑。请为 [城市/道路/事件] 写一段可玩的中文文本和对应英文文本。
玩家身份是 [身份与称呼]，当前处境是 [钱、同行者、线索、日期]，叙事使用第二人称“你”。
先给一个可感知的动作或细节，再让当地人物以自己的身份说话，最后给出明确选择。
每个选择都必须说明玩家能做什么；结果必须准确反映 effects 中的金钱、物品、天数、关系和线索。
写出至少一个具体地方细节（食物、舞步、织物、器物、口音、道路或天气），不要用“异域”“热情好客”代替细节。
人物不要替玩家宣告命运；占卜只能作为游戏内的解释，不作现实断言。
区分 source / hybrid / authored，给出书名、段落或事件 ID；找不到原文时不得伪造引文。
长度：入城短简介 35–70 中文字；场景正文 120–260 中文字；结果反馈 25–80 中文字。
输出：zh、en、effects 对照表、lore 来源、待审风险。
```

语言统一规则：叙事使用自然现代中文，保留中世纪称谓和具体物产；人物说话体现关系和处境，不让每个人都使用同一种文风；玩家身份名称使用已确认的“丹吉尔式旅人”“威尼斯商旅”等沉浸称呼，不改成生硬的历史人物姓名。英文与中文先对齐事实，再分别调整节奏，不逐字硬译。

## 视觉 Prompt

```text
为 FateQuest 绘制 [角色/地点/牌面]，云岭暮光风格：纸本旅行札记的细腻纹理，低饱和矿物色，暖金色光线，清楚的前中后景，边缘保留手绘线条。
画面服务于 [eventId/sceneId/cardId]，时代为 [年份]，地点为 [城市与区域]，主体为 [一个明确的人或物]。
给主体留出 UI 安全区，缩略图仍能看清脸、手势、器物和关键符号；不要把多人拼在一张需单人绑定的图里。
服饰、发式、器物、建筑和动作只根据角色 brief 与来源资料绘制；文化、宗教、职业和性别不能用通用标签自动猜测。
禁止现代物件、文字水印、假拉丁字、重复肢体、邻人残边、棋盘格、空白占位字样和无法读出的牌面标题。
输出：512×768 或该资源既有规格，透明背景按需求，文件名 [canonical stem]，并附角色/地点/来源/版本 hash 记录。
```

角色图必须“一人一图一 ID”；场景图必须能指出对应城市、事件或地点，不能用三条带组图冒充三个独立场景。牌面必须先确认编号体系再出图：易经采用文王序 1–64，输入位掩码由程序映射，画面不得自行推断序号。

## 音乐与音效 Prompt

```text
为 FateQuest 制作 [culture] × [scene] × [mood] 的循环音乐/环境音。
这是中世纪欧亚旅行叙事的合成声景，不冒充田野录音或“代表整个文化”的真实传统音乐。
保留一个可辨认但克制的核心质感，给对话和环境留出频段；drone/pulse/melody/color 四层各有清楚职责。
循环首尾要经过实际连续播放检查；记录 BPM、调式/音阶只是制作参数，不把它们写成历史真实性证明。
环境音注明地点、天气、路线方式和来源；现代录音或替代音色必须如实标注。
输出：44.1kHz mono OGG、循环长度、seed、输入来源 hash、输出 hash、预期触发条件和未解决的听审风险。
```

音乐统一的是动态和空间关系：城内比道路更有细节，圣所更克制，危险提高脉冲但不把所有地方变成战斗音乐；海路不用骆驼铃和沙地风作为默认床。音量、循环、跨文化淡入和静音恢复必须在真实窗口中验证，解码成功不算听审通过。

## 生产记录模板

```yaml
id: <eventId|sceneId|cardId|audioId>
source_prompt: docs/library_audit/STYLE_BIBLE_2026-10-20.md#<section>
input_refs: []
output_paths: []
source_hash: <sha256 or n/a>
output_hash: <sha256>
editor_or_artist: <name and role>
review_date: <YYYY-MM-DD>
review_scope: <facts / language / visual / listening / runtime>
status: draft | needs_revision | agent_checked | human_approved
risks: []
```

`agent_checked` 只表示自动或代理检查完成，不能写成 `human_approved`。任何换图、重录、改写或源文更新都要重新生成 hash 并重新审阅。

## 统一验收顺序

先验身份与来源，再验内容和效果，随后验真实接入，最后做跨域审阅：玩家看到的文字、人物、场景和声音必须描述同一处境。素材不完整时应显示诚实的场景/文字回退，不能静默借用另一个文化或角色的素材。
