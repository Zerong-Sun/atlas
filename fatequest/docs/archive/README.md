# 历史文档归档说明

这里保存已经完成、被替代或仅用于审计追溯的规划与需求记录。归档内容不作为当前实现依据。

请从 [`../REQUIREMENTS_INDEX.md`](../REQUIREMENTS_INDEX.md) 进入现行需求、状态、计划和验收命令。

归档规则：

- `PLAN-*`：已完成批次或被新计划替代的执行计划。
- `AUDIT-*`：历史审计快照，数字只代表当时的工作区状态。
- `GDD-*`、`ATLAS_PORT.md`：旧设计或旧版本移植参考。
- `art-prompts/`：已完成批次的生成提示词和素材记录。

如果归档记录与现行文档冲突，以 `STATUS.md`、`PLAN.md`、`ROADMAP.md` 和
`FATEQUEST_ENGINE_REQUIREMENTS.md` 为准。
