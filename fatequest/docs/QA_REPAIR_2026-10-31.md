## 发现与修复

| 问题 | 修复 | 复核 |
| --- | --- | --- |
| 旧测试命令使用正常 `user://`，可能改写玩家存档和设置；本轮早期测试已生成过测试存档。 | 新增 `tools/test/run_isolated_godot.mjs` 与 `run_smokes_isolated.mjs`，各测试独立运行并清理目录。早期生成的六个测试存档已移至正常用户目录中的 `.codex-test-saves-2026-10-31/` 保存；`ui.cfg` 没有测试前备份，保留现状。 | 56 项冒烟与内核套件均从隔离目录完成；正常用户目录没有新增同名测试槽。 |
| 续行冒烟把仅适用于罗布至沙州的“沙漠之声”放在大不里士至巴格达。 | 样例改为该路线上可触发的 `ev-road-22`。 | 续行冒烟通过。 |
| 面板动效冒烟仍检查已移除的旧 `TextureRect` 装饰，误报失败。 | 改为检查现用的 `ReadingOrnament`，并检查高对比与普通样式的切换。 | 面板动效冒烟通过。 |
| 南金与提州新增探索后，旧冒烟仍要求两处地点，误报失败。 | 检查至少两处且所有地点 ID 不重复，保留逐地点界面检查。 | 城市地点冒烟通过。 |
| 亚历山大港接待事件已绑定搬运工肖像，但图像没有登记进审阅清单，肖像冒烟失败。 | 核对现有单人图片后补齐肖像映射、标签和带 SHA-256 的审阅记录；保留人工文化审阅状态。 | 肖像映射冒烟通过，静态门禁通过。 |
| 文档中的故事键数和部分测试数已过期。 | 更新现行数字与隔离测试命令。 | 命令复跑通过。 |

本次图形启动验证了窗口能打开并加载内容；画面排版、长时间游玩体验及肖像文化适切性仍需要人工逐项审阅。内核套件日志中的 `ERROR`／`WARNING` 来自故意测试无效输入和损坏存档的用例，所有模块与整套测试均返回成功。
