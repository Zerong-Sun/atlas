# Runtime Tarot: complete Rider–Waite–Smith profile

The active deck is `rws_commons_public_domain`: 78 original Rider–Waite–Smith card reproductions from Wikimedia Commons. Artwork: Pamela Colman Smith; design: Arthur Edward Waite; original publication 1909–1910. The 40 earlier Cloud-ridge Twilight paintings are retained in `_legacy_cloud_ridge/` as an incomplete, separate profile. They are never fallback faces for this deck.

`DECK_MANIFEST.json` records each content ID, Commons file page and download URL, the downloaded source SHA-1/SHA-256, the Commons original SHA-1 reference, SHA-256 for output, dimensions, exact per-file license metadata, retrieval date and conversion parameters. `_sources_rws/` preserves the downloaded JPG bytes: 74 original-size sources plus 4 standard 960px Commons thumbnails, following the server’s explicit rate-limit guidance. Original-size downloads are checked against the Commons SHA-1; thumbnail downloads record their actual returned URL and hashes separately from the full-size original hash. Runtime WebPs preserve all decoded source pixels and downloaded dimensions through lossless conversion; no recoloring, crop, frame or repaint is claimed. `tools/art/import_public_tarot.py` checks all sources before replacing runtime faces.

Commons identifies these original artworks and faithful reproductions as **Public domain**, not CC BY or a proprietary modern recoloring. Public Domain Mark is a status marker, not a newly granted copyright license. Each record retains the specific Commons statement; the source is not generalized into a claim that every later RWS edition, recoloring, trademark or restoration is public domain. Reference file pages include [Five of Cups](https://commons.wikimedia.org/wiki/File:Cups05.jpg), [Ace of Swords](https://commons.wikimedia.org/wiki/File:Swords01.jpg), and [Ace of Pentacles](https://commons.wikimedia.org/wiki/File:Pents01.jpg). No third-party GitHub code license is used as an artwork license.

This is an intentional complete deck profile, keeping consistent original RWS linework and composition across all 78 faces. Scan paper/colour/print differences can remain and require visual signoff. It is a modern divination reference, **not evidence of a 14th-century traveller carrying this 1909–1910 deck**. Historical presentation must preserve that distinction.

Automated acceptance: 78 unique content IDs and output hashes, source hash verification, all JPG/WebP decoding, pixel-preserving conversion, and 78 Godot resolver results without legacy fallback. These checks do not constitute human art, historical or legal approval. Human art/history signoff remains pending. Original Cloud-ridge artwork can later become an alternative profile only after all 78 matching cards are completed and reviewed together; use `assets/art/ART_PROMPTS_TAROT_DECK.md` for that separate production queue.
