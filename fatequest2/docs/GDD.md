## 0. 电梯陈述

《灵游》是一款以**世界占卜文明**为核心机制的叙事旅行游戏。玩家扮演执罗盘的行者,沿真实历史游记的路线穿行诸文明:在威尼斯抽塔罗、在波斯观星择日、在中原起卦、在泉州掷筊。**占卜不是查看结果的按钮,而是你的移动方式、资源系统与叙事之笔。**

**四个独到之处(USP)**

1. **占卜系统即游戏系统**:每种占法的真实规则(纳甲、逆位、五行、圣笑阴筊)直接成为玩法规则,不是换皮抽奖。
2. **真实游记驱动的世界**:HiSMap 内容管线把任何一本游记(公版原文)加工成一章可玩地图——内容可无限扩展,"赛季=新的一本书"。
3. **同一符号,诸文明异读**:跨文化对照(Atlas 的共识/分歧)成为策略机制(见命途塔"文明共鸣")。
4. **与命运博弈,而非被随机摆布**:预兆可视、改运资源、凶签开险路——每个"坏结果"都有可用的一面。

平台:PWA(Web + 移动安装)→ Capacitor 上架;内容后台复用 HiSMap(FastAPI + PostgreSQL)。

## 0.5 世界观定位:中世纪游记宇宙(v1.1 新增)

游戏世界锚定在 **1250–1450 的中世纪游记时代**:每一章 = 一本真实游记 = **一双看世界的眼睛**。同一个欧亚大陆,不同文明的旅人走过、记下、占问——玩家依次借用他们的眼睛,最终发现这些路线在地图与史实上彼此交叠(马可·波罗与伊本·白图泰都到过刺桐港)。**跨章交叠点是长线叙事的针脚。**

| 章 | 游记 | 之眼 | 路线 | 状态 |
|---|---|---|---|---|
| 一 | 《马可·波罗行纪》1271–1295 | **基督之眼** | 威尼斯→阿卡→(大不里士)→霍尔木兹→〔克尔曼沙漠/赫拉特商道〕→帕米尔→上都→大都→〔驿路/运河·行在〕→泉州→归航断案 | ✅ 已上线(12 节点双岔路) |
| 二 | 《伊本·白图泰游记》(里赫拉)1325–1354 | **新月之眼** | 丹吉尔→开罗→〔麦加/红海〕→德里→卡利卡特→泉州(刺桐再会) | 接口已就绪(schema 完整占位,待管线填充) |
| 三 | 马欢《瀛涯胜览》1413–1433 | **儒道·妈祖之眼** | 南京→长乐→占城→满剌加→古里→忽鲁谟斯 | 规划(§9.3 已有 book.yaml 示例) |
| 四 | 鄂多立克《东游录》/《曼德维尔游记》 | **传说之眼** | 真实路线上叠加中世纪传闻怪谈(狗头人、长老约翰) | 远期(与谜纹系统联动) |

**世界观三原则**
1. **同一大陆,异读成章**:章与章共享同一张欧亚底图与城市坐标;换章=换配色、换占法、换叙事腔调,地理不变——玩家会认出"我来过这里"。
2. **交叠即彩蛋**:前章走过的节点在后章留下痕迹(威尼斯人的账本残页、驿站里的旧刻字),跨章信物可携带(§5.6 谜纹)。
3. **占法随眼睛换**:基督之眼用塔罗/星辰骰,新月之眼用观星/沙占/伊本·西林解梦,儒道之眼用卦/签/筊——**换一双眼睛=换一套提问方式**(P3 的世界观表述)。

## 1. 现状诊断(为什么"没有游行感")

| 症状 | 根因 | 对策(章节) |
|---|---|---|
| 节点像按钮抽奖 | 单线路网,无取舍 | 路线网+海陆分支 §4.1 |
| 没有"在路上"的过程 | 节点之间零内容 | 行进段+遭遇卡+镜头跟随 §4.3 |
| 无时间压力与规划 | 无时间维度 | 天数系统+目标天数 §4.2 |
| 无情感牵挂 | 无人同行 | 旅伴系统 §4.4 |
| 失败=重试,无策略 | 结果二元 | 预兆/改运/双刃结果 §3 |
| 氛围单薄 | 无雾、无声、无昼夜 | 呈现规范 §7 |
| 内容一次性 | 手工造关卡 | 游记管线+Schema §9 |

## 2. 设计支柱(所有需求用此四条裁决)

- **P1 旅程实感**:一切系统服务"在路上"的体感——时间流逝、风土渐变、旅伴聚散、日志留痕。
- **P2 占卜即操作**:玩家每个主动行为都是一次有手感、有悬念节拍、有代价的仪式。
- **P3 文明的语法**:换一片土地=换一套提问方式;文化差异必须落在机制上,而不只是美术上。
- **P4 敬畏与游戏并存**:对活着的信仰保持尊重;游戏性放在旅程、解谜、构筑上,永不放在"嘲弄仪式"上。

## 3. 核心循环与"命运博弈"机制

**微循环(30 秒)**:遭遇 → 择占法 → 仪式操作(拖、掷、摇,见 §7.3)→ 悬念揭示 → 解读应用 → 后果反馈。
**局循环(15–30 分钟)**:一段路程或一次登塔:规划(路线/构筑)→ 3–6 个微循环 → 节点结算(日志+收集+资源)。
**元循环(日/周)**:章节推进、图鉴扩充、罗盘升级、每日一签、赛季新章。

让占卜从"随机数"变成"博弈"的三层机制(全模式通用):

1. **预兆可视**:仪式开始前泄露部分信息——牌背泛金光=大阿卡纳概率高;掷筊前香炉烟直=圣筊概率+10%;起卦前云气偏蓝=坎水倾向。玩家据此决定**要不要问、用什么问**。
2. **改运资源(星尘)**:可花星尘"翻转逆位""重掷一爻""再求一筊"。存量稀缺、跨模式共享——每次使用都是决策。
3. **结果双刃**:每个占卜结果都开启不同的路,而非"成/败"。凶卦解锁险路(天数-3,风险+2);阴筊指向暗线剧情;逆位牌在特定遭遇反而是解法。参考《80 Days》:没有失败,只有更曲折的旅程。

## 4. 模式一:占途 · 千载行纪 2.0(主线)

### 4.1 路线网

每章地图从单链改为**网状图**(nodes + edges,schema 见 §9.5):主线 8–12 节点,支路 4–8 节点。关键取舍点提供 2–3 条路线:

- 例(马可·波罗章):霍尔木兹之后,**陆路**(克尔曼沙漠:天数少、风险高、需火/土吉兆)vs **海路**(印度洋:天数多、遇季风事件、妈祖护佑提前生效)。
- 支路节点埋:稀有图鉴符号、旅伴个人事件、断案前置线索。走过的边在世界总图上永久点亮(长线收集)。

### 4.2 时间、行囊与交易

- **天数**:回合制时间,无实时压力。每条边消耗天数,遭遇可增减。章节给**逍遥天数**(par):低于 par 结算加成,超过只减少奖励、不判失败(P1:旅程不该被判死)。
- **行囊(9 格)**:占具(法器,带被动:水晶球=预兆强化)、商货(丝绸/香料/琉璃,城镇差价交易补盘缠——轻量《80 Days》贸易)、信物(叙事道具,断案与旅伴事件消耗)。
- **盘缠**曲线由校验器保证不软锁(§9.2)。

### 4.3 行进段(核心增量:把"游"做出来)

节点间不再瞬移。点击出发后:

1. **镜头跟随**:驼队/帆船小像沿 SVG 路径移动(8–15 秒),云雾在前方翻卷、沿途地名浮现又后退;可随时跳过(尊重时间)。
2. **途中遭遇 1–2 张**:遭遇卡从章节池按 `when` 条件(区域/天气/携带物)加权抽取。三选一结构,**至少一项是"以占问之"**:
   - 直接选项:确定的小收益/小代价;
   - 占卜选项:高方差+护佑加成+可能开启隐藏分支——让"问"永远是有趣的那个选择。
3. **天气参与玩法**:雾(遭遇"迷路",需占卜辨向)、顺风(天数-1)、风暴(强制事件,险中有宝)。天气由日种子+区域气候表生成,预报可通过茶肆传闻获得(情报=资源)。

### 4.4 旅伴

每章 2–3 名(史实+虚构混合,马可章:波斯星家帖必烈、泉州船娘林三娘)。

- **文明视角技能**:星家每程可重掷星骰一次;船娘使掷筊前三掷免耗且预兆更准。
- **好感与个人事件**:支路节点触发;好感影响断案证词的深度。
- **证词偏见**:断案时旅伴按自身文明解读线索,方向可能相左——文化差异第三次成为机制(P3)。

### 4.5 节点城镇(轻 hub,四键即走)

市集(交易)| 庙宇/教堂/道观(做一次当地仪式,得护佑与预兆)| 茶肆(传闻:下一段路的天气与遭遇情报)| 行馆(日志回顾、休整+1 体力)。不做跑图,每个建筑一屏。

### 4.6 行者日志(自动生成叙事)✅

每段路自动生成一页"行纪":模板+变量(日期、天气、遭遇、占卜结果、旅伴一句话反应),配小图。章末装订成《行纪册》,可导出长图分享(传播点)。文风参考原著摘录口吻,中英双语。

### 4.7 环游模式(v1.1 新增,《80 Days》对标)

把"选路"从岔路口扩展到**每一段路**:

**① 交通方式即选择**。同一条边可有 1–3 种交通方式,各自独立结算:

| 方式 | 天数 | 盘缠 | 风险 | 专属内容 |
|---|---|---|---|---|
| 🐪 驼队 | 基准 | 低 | 中 | 沙暴/驼铃/商队遭遇池 |
| ⛵ 海船 | 快(顺风更快) | 中 | 风暴 | 妈祖/星辰导航遭遇池 |
| 🛶 河船 | 慢 | 低 | 低 | 运河风物、交易机会 |
| 🐎 驿马 | 最快 | 高(或需金牌信物) | 高 | 官道盘查、限时事件 |

数据层:`edge.modes[]` 替代单一 `kind`(向后兼容:无 modes 即单方式)。**信物解锁交通**——大汗金牌开驿马,天妃香符降海路风险:道具第一次直接改写地图通行性。

**② 风景卡(风物志)**。每段行进结算 1 张风景卡:插画位 + 50 字风物短文(帕米尔的淡火、霍尔木兹的热风)+ 收藏入《风物志》图鉴。风景卡按〔章 × 交通方式 × 天气〕生成变体——坐河船看到的行在与走驿路看到的不同,**重玩的理由藏在风景里**。集齐一章风物志 → 解锁该章「画匠视角」(地图换手绘水彩皮肤)。

**③ 对话卡**。城镇与行进途中,旅伴/NPC 以对话卡形式攀谈:2–3 轮短对话树,选项影响好感、情报或小额资源;对话内容从游记原文的轶事改写(马可章:大都的纸币、行在的十二千座桥)。**对话是文化注释的活化**——§7.4 的史料小卡长出了嘴。

**④ 环游总图**。多章完成后,世界总图把各章金线拼成一张环欧亚的网;「环游者」成就线:集齐两章共有节点(泉州)、三种文明的护佑、四种交通方式各行一程。

### 4.8 里程与远期:环球扩展

中世纪游记走完后,同一引擎滑向大航海(《伊本·马吉德航海书》、麦哲伦)与近代(真·八十日环游)——"赛季=新的一本书"不变,世界随书越转越大。

## 5. 模式二:占卜肉鸽 ·「命途塔」

**定位**:20–30 分钟一局的构筑肉鸽;象征系统真正变成棋子。入口在星图,与主线共享图鉴与星尘。

### 5.1 Run 结构

- 12 层 + 3 道**命劫**(第 4/8/12 层 boss 事件)。
- 开局选**行者流派**(=职业):塔罗行者 / 易卜师 / 符文萨满(首发三种;各有起始符号组 6 枚与专属改运技)。
- 每层:抽取一个**情境事件** → 从手中符号库**打出 2 枚**应对 → 结算 → 三选一新符号(或强化/净化)。

### 5.2 符号=棋子(设计表节选)

符号库上限 12 枚,跨文明混编。效果=真实占义的游戏化:

| 符号 | 正位/本义 | 逆位/变爻 |
|---|---|---|
| ☀️ 太阳(塔罗) | 本层奖励 ×2 | 下层预兆全隐藏 |
| 🗼 高塔(塔罗) | 摧毁当前负面状态,受 2 伤 | 随机弃 1 符号 |
| ䷀ 乾 | 行动类选项必成 | (变爻)转 ䷫:遭遇"不期之遇" |
| ䷜ 坎 | 险境事件收益 +100%(赌) | 失败代价也 ×2 |
| ䷎ 谦 | 本层风险 -2 | — |
| ᛉ Algiz | 护盾:抵挡一次伤害 | 倒位:护盾给敌意 NPC |
| ᚠ Fehu | +15 金币 | 倒位:被课税 10 |
| ᛁ Isa | 冻结:跳过本层事件 | — |
| 🌙 月亮(塔罗) | 查看下一层的两个暗选项 | 本层文本谜面化(高风险高报) |

**文明共鸣(独创策略核)**:同层打出的 2 枚符号——

- **异文明** → 触发「对照」:两效果各 +50%,并显示一条真实的文化对照小注(玩着玩着学到东西);
- **同文明** → 触发「同源」:合并为更强的单效果(如 双塔罗=强制正位)。
构筑张力:纯派系深度 vs 跨文明广度。

### 5.3 事件类型与命劫

风物(资源)、交涉(NPC,符号当"论据")、险境(赌)、商队(购/换/净化)、奇遇(图鉴稀有符号)、**命劫**:3 回合内凑出指定组合,如「风暴劫:打出水系符号 ≥2 或 Algiz」。命劫源自章节世界观(风暴/关税/瘟疫/猜忌)。

### 5.4 代价与元进度

- **塔之逆位(诅咒符号)**:强力奖励附带塞入库中的负面符号,占格子——净化有价。
- 结算 → **星尘**(按层数+共鸣次数)→ 解锁新符号入池、新流派、开局遗物。
- **与图鉴互通**:主线图鉴点亮过的符号才会进入塔的掉落池——两个模式互相喂内容,解决"玩塔不玩主线/玩主线不玩塔"。✅(实装另加:Balatro 式**弃换**——每层一次弃选重抽;预兆闪光;力量圆片;计分跳数与震屏)

### 5.5 文明小游戏(v1.1 新增,Balatro × 动物井的"手上功夫")

每种占法配一个 5–15 秒的**微操小游戏**,替代"点按钮等结果"。原则沿用 §7.3:**手感影响演出与小额奖励,不影响占卜概率**(手感≠作弊)——但漂亮的操作给"仪式分"(星尘碎屑、图鉴加速)。

| 占法 | 小游戏 | 操作 | 仪式分判定 |
|---|---|---|---|
| 掷筊 | 蓄力抛掷 | 长按蓄力,松手定弧线 | 落点入香案圆心 |
| 铜钱卦 | 三连节拍 | 按节奏点三下(渐快) | 全中节拍窗口 |
| 塔罗/雷诺曼 | 切牌手感 | 拖拽切牌,速度决定翻牌演出 | 匀速切完一叠 |
| 卢恩 | 摸符 | 袋中拖拽晃动,倾斜倒出 | 三枚同屏落定 |
| 星辰骰 | 星盘对准 | 转动星盘环对齐当夜星位 | 三环误差 < 5° |
| 梅花心易 | 心算起卦 | 报数窗口内心算加和 | 答对卦数 |
| 命途塔·命劫 | 组合闯关 | 3 回合凑组合(已有)✅ | 提前 1 回合达成 |

小游戏全部可在设置关闭(无障碍),关闭后自动满仪式分的 50%。

### 5.6 谜纹系统(v1.1 新增,《动物井》的分层秘密)

**动物井给我们的不是玩法,是结构:通关只是第一层。**

- **L1 · 旅程层(所有人)**:正常通关章节与命途塔——现有内容。
- **L2 · 收集层(细心人)**:32 枚**谜纹**(⌘ 形小刻印)藏在世界里——地图角落一次性热点(点到即得)、特定天气才显形的节点暗纹(雾天的威尼斯钟楼)、图鉴页边角(集齐某组符号后浮现)、行纪册第 N 页页脚、命途塔特定层的事件暗选项。谜纹本身给微量星尘;**每 8 枚合成一枚「古印」**,四枚古印对应四文明,各解锁一间**秘阁**(隐藏房间:一段删节游记 + 一件遗物 + 一枚塔符号)。
- **L3 · 谜题层(社区)**:秘阁墙上的四段密文(凯撒盘/卦序/如尼替换/星盘度数)拼出**「第三十七张牌」**坐标——全图鉴唯一的隐藏收藏,指向下一章的启程港。设计为**单人可解但社区更快**,自然生成攻略讨论。
- 实现规格:`FQ.GLYPHS[]`(id/章/触发条件/坐标),状态入 `state.glyphs`;谜纹热点渲染为 2–3px 微光点,命中区 24px;**绝不影响主线通关**(P1:秘密是馈赠,不是门槛)。

## 6. 断案 2.0(每章 1–2 桩)

- **证据链**:每条线索带隐藏指向标签(如 `[海中][自愿][守密]`);结论选项需 ≥2 条支持标签才解锁——从"猜答案"变"拼图"。
- **追问**:每种占法可追问一次(换问法重问,消耗护佑),得到更具体的第二线索。呼应真实占卜"问法决定答案"的核心观念(P3)。
- **旅伴证词**:按好感解锁,且带文明偏见(星家倾向宿命解释、船娘倾向民俗解释)——玩家需要自己裁断。
- **轻因果**:结局评级写入日志,影响下章开局资源与旅伴初始态度。

### 7.1 视觉:地图七层渲染

| L5 | **云雾层**:未探索区浓雾 0.85,已探索轻霭 0.25;雾随风向缓慢流动,节点解锁时雾旋涡状散开(1.2s) | canvas,柏林噪声 2 octave,60fps 降级 30fps |

**镜头语言**:进章 2s 缓推至当前节点;行进段跟随小队;断案切近景卷轴视图;章末拉远展示全程金线——"你走过的路"是最终奖励画面。

### 7.2 音频设计

**区域主题(同一主旋律,换配器=「文明变奏」,听觉记忆点)**

| 区域 | 配器 | 环境声层 |
|---|---|---|
| 基督之境 | 鲁特琴、圣咏垫音 | 钟声、鸥鸟、缆绳 |
| 新月之境 | 乌德琴、奈伊笛 | 风沙、驼铃、市集人声 |
| 儒道之境 | 古琴、箫 | 蝉声、檐铃、更鼓 |
| 妈祖之海 | 南音琵琶、海浪垫 | 浪涌、帆索、船工号子 |

- **跨区 crossfade 8s**,旋律不断、乐器渐变——玩家"听见"自己跨过了文明边界。
- **仪式音效三段式**(起手/悬念/揭示):掷筊=竹木双响落地;抽牌=纸滑+翻转嗡鸣;铜钱=三枚错落金属声+滚动;摇签筒=竹筒节奏由慢渐快至一支跳出。悬念段 0.8–1.2s 静默或心跳低频——**揭示前的呼吸感是占卜体验的灵魂**。
- 实现:Web Audio API;每区 1 个 loop(~40s)+ SFX sprite;按区懒加载(≤1MB/区);全局音量与静音入口。

### 7.3 微交互与手感

- **长按蓄力掷筊**:力度影响抛掷动画弧度与旋转(不影响概率——手感≠作弊);
- **拖拽抽牌**:从扇形牌堆拖出翻转,拖速影响翻牌速度;
- **摇一摇**(移动端 DeviceMotion,可选):摇签筒/摇符袋真实体感;
- **触觉反馈**:揭示瞬间短振,圣筊/大吉双振;
- 所有仪式遵循**预兆 → 操作 → 悬念 → 揭示 → 余韵**五拍节奏,余韵=结果文本打字机+粒子。

### 7.4 文本呈现

行纪摘录打字机逐字浮现于纸纹卡片;关键词可点(「圣墓灯油」「刺桐」),弹出 80 字史料小卡——**文化注释即内容**,不打断主流程。

## 9. 内容管线与数据规范(后台游记接口)

### 9.1 管线总览

```
原文(PDF/EPUB/TXT/MD)
  → HiSMap pipeline:ingest → segment → extract(地点/人物/日期/摘录/可信度)
  → 新增 gamify 阶段:自动草拟 节点/路段/遭遇/案件(LLM+规则)
  → Admin 编辑器:人工审核、调参、试玩
  → validate:Schema 校验 + 1000 次自动模拟通关
  → publish:版本化章节包(纯静态 JSON)→ CDN
  → 客户端增量拉取(离线优先,后台不可用不影响已装章节)
```

### 9.2 Admin API(FastAPI,复用 HiSMap backend,JWT)

```
POST   /api/admin/books                    # 登记游记(元数据+原文上传)
POST   /api/admin/books/{id}/process       # 触发流水线(异步)→ job_id
GET    /api/admin/jobs/{job_id}            # 进度/日志
GET    /api/admin/books/{id}/draft         # 取自动生成的章节草稿
PUT    /api/admin/chapters/{id}            # 保存编辑(草稿区)
POST   /api/admin/chapters/{id}/validate   # 校验(见下)
POST   /api/admin/chapters/{id}/publish    # 发布 → 生成 semver 版本
GET    /api/chapters/index?since={version} # [公开] 客户端增量拉取
GET    /api/chapters/{id}/{version}.json   # [公开/CDN] 章节包
```

**校验器(validate)三件事**:① JSON Schema 严格校验;② 图连通性(起点可达终点、无孤岛、案件线索标签闭合);③ **1000 次蒙特卡洛模拟通关**:门槛通过率、盘缠曲线、平均天数 vs par、软锁检测——不通过不给发布按钮。

## 10. 技术方案

- **前端**:仍为无框架 PWA 渐进演进。模块:`core/`(engines、state、schema-lite 校验)、`modes/`(journey、tower、cases)、`fx/`(fog、weather、audio、camera)、`data/`(chapter loader,IndexedDB 缓存章节包)。
- **性能预算**:首屏 <200KB(不含音频);章节包 <150KB;音频按区懒加载;雾层在低端机自动降 30fps/关粒子。
- **后端**:HiSMap FastAPI 扩展三张表(chapters、chapter_versions、jobs);发布产物为纯静态 JSON——**客户端对后端零强依赖**,离线完整可玩已下载章节。
- **移动打包**:Capacitor 原样包裹;DeviceMotion/haptics 通过插件增强。

## 12. 风险与边界

- **宗教呈现红线**:妈祖/教堂/清真寺场景中仪式必以敬畏笔触呈现;不在圣所做戏谑失败动画;伊斯兰区避免拟人化神明形象,占法采用历史上真实存在的沙占/星学;上线前敏感读者审阅。
- **占卜与迷信边界**:全局"娱乐与文明探索"声明;概率公示;**永不做付费抽卦/改运付费**(星尘只能玩出来)。
- **AI 内容**:gamify 草稿必经人工审核签发(curator 字段留责任人);史实注释需给出处。
- **版权**:公版原文优先;译本授权在 book.yaml 声明并随章节包展示。
