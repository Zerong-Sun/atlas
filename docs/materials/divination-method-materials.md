## Cross-Method Implementation Notes

- All methods need a shared schema: `inputs`, `symbols`, `spread_or_chart`, `single_symbol_meaning`, `combination_logic`, `safety_notes`, `sources`.
- Avoid deterministic predictions in UI copy. Use “倾向、提示、可作为反思” instead of “一定、必然、注定”.
- High-risk domains should route to safe copy: medical, legal, investment, self-harm, surveillance of third parties.
- Corpus entries should mark source type: public domain, self-authored, licensed, or citation-only.
- Good first build order: 雷诺曼牌/占星骰子/签诗 are cheaper UI wins; 六爻/梅花 are medium; 奇门/紫微/风水 need more domain logic.
