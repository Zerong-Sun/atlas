# 占法完整度审阅

本文件用于追踪 Web 与 Mobile 端占法是否只是“列在目录里”，还是已经具备可运行、可解释、可归档、可复盘的完整体验。

## 完整可用标准

一个占法进入 `ready`，至少需要满足：

- 目录可见，且 Web / Mobile 都能打开。
- 有真实 engine 或结构化规则，不是空白占位。
- 有输入工作台，能体现该文化的方法特色。
- 有结果可视化或结构化呈现，而不只是长文本。
- 结果能进入档案 / 记忆存储，并可交给 Method Copilot 追问。
- 有文化说明：来源文明、适合怎样提问、术语如何跨语言显示。
- 有安全边界：不做确定性命运承诺，不替代医疗、法律、投资建议。

## 需要继续深化的点

- **吠陀 Mobile 精度**：Web 使用 Swiss Ephemeris / Lahiri；Mobile 当前是基础移动版，需要找到可用于 RN/Hermes 的星历方案，或迁到 Edge Function 计算。
- **面相 / 手相**：当前是自我观察表单，不做图像识别。若要上传图片，必须先设计隐私、歧视和误判边界。
- **Geomancy 土占**：已补法庭图、十二宫和“按问题类型自动取用神宫”。下一步可继续加入相邻宫、传递、完美/不完美判断与反复出现图形分析。
- **占梦**：已补中国梦占、荣格、民俗征兆、精神反思，并按语言 / 文化镜头生成适配说明；后续应让 LLM 直接按文化偏好生成细分流派解读。
- **国际化**：当前已具备语言 / 文化偏好和术语策略，但还没有全量 UI 文案字典。下一步应建立 `@atlas/i18n` 或共享 message catalog。
