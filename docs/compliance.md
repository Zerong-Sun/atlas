# 合规与内容边界（MVP）

## 表达原则

- 使用「象征解释、传统观点、反思建议、趋势倾向」，不承诺绝对预测。
- 健康、法律、投资类问题必须附带「请咨询专业人士」提示。

## 古籍与版权

- 仅入库 `public_domain` 原文与 `self_authored` 译文/注释。
- 每条 `source_chunks` 记录须含：`source_type`、`license_note`、`source_url`（如有）。
- 展示层区分：原文 / 翻译 / 注释 / AI 推理 / 建议。

## 宗教与文化

- 伊斯兰梦境相关内容仅作精神反思，不使用 fortune telling 表述。
- 各体系在书库中提供简要文化背景说明（`tradition_intro`）。

## 引用防幻觉

- 解读中的古籍引用必须来自检索白名单 `chunk_id`。
- 历史报告使用 `citation_snapshots` 冻结，语料升级不影响已生成报告。
