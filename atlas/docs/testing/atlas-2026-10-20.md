# Atlas 手机测试与修复记录

日期：2026-10-20。范围：Atlas；FateQuest 是另一个独立项目。本次未发布线上站点，Vercel 自动部署仍关闭。

## 手机入口

电脑与手机连接同一个 Wi-Fi，保持开发服务运行：

- 手机浏览器：`http://192.168.0.8:5174/methods`
- Expo Go：`exp://192.168.0.8:8081`，二维码见本目录 `expo-lan-qr.png`。
- Expo SDK 为 54；扫码设备须使用兼容的 Expo Go。当前 Metro 提示 expo、expo-constants 有同 SDK 补丁可升级，本次没有迁移 SDK。若设备客户端不兼容，先用浏览器完成体验检查。
- IP 变更后二维码需重新生成。浏览器与原生客户端的本机存储彼此独立；不能将它们误当作已经云同步。

重启命令（在 atlas 根目录分别打开终端）：

```sh
npm run dev -w @atlas/web -- --host 0.0.0.0 --port 5174
npm run dev:mobile:lan
```

## 核心修正

1. 周易旧实现用 hash 分别抽本卦/变卦，并误把文王卦序当作六位二进制。界面还将 6/9 阴阳标反、等概率取 6–9。本次改为三枚独立铜钱，概率 1:3:3:1；初爻到上爻成卦，6 老阴、9 老阳发生变化。保存算法版本和实际六次记录。
2. 纳甲六爻修正卦序映射、完整八宫表、世应位置和内外卦纳甲。不同软件仍应统一时间、节气、流派与取用规则。
3. 梅花易数按实际中间四爻生成互卦，由动爻确定体用及变卦。数字法与农历时间法明确分开。
4. 西占把赤经误作黄经的问题改正，使用地心黄道坐标，校验日期、时差与经纬度。
5. 手机版印度占星旧哈希模拟星位被真实离线天文计算替换。Web 原 Swiss 浏览器依赖出现 `exports is not defined` 白屏，现两端统一可移植计算。使用近似 Lahiri、平均月交点、整宫制。
6. 签诗标为 Atlas 原创；不再冒充寺庙传统全本。学习资料摘要不再与逐字古籍引文混淆。

同一问题在不同软件随机起卦本来就可能不同；有效对照需要输入完全相同的六个数，并统一初爻方向。本次修正前的历史结果可能有错，旧记录未被静默重写。

## 原典、检索与数据库

- 原始资料在 `packages/engines/src/data/iching-classics.json`：64 卦卦辞、64 大象、384 爻辞、用九用六，逐条保留来源 URL、页面修订号和 SHA-256。
- 引擎的 TS 数据由同一 JSON 生成，回归测试检查两者完全一致。
- 检索种子库保留现有 UUID，更新 578 条周易记录；卦辞/大象/爻辞与引擎同源。不再把原文重复句冒充白话译文。现有全库 1,979 chunks；校验通过只证明格式和来源字段齐全，不等于全部经过人工学术审校。
- `scripts/import-iching.py`：导入原典；`scripts/refresh-iching-corpus.mjs`：同步周易检索种子；两个 seed-builder 也已改为读取统一原典。
- `scripts/export-culture-catalog.ts`：生成增量 SQL。迁移 `20261020000000_culture_catalog.sql` 新增 64 卦目录、24 文化课程；公开只读 RLS，不改用户记录。
- **迁移尚未应用远程 Supabase**。当前会话仅存在旧项目引用，未发现可用的 Supabase CLI、管理令牌或数据库连接串，因此未尝试写入远程数据库。当前两端离线内置资料可用，文化笔记保存本机。既有云端检索库要同步新版种子后才会获得相同原文。

## 图像与运行成本

一次生成 4×3 合图，实际尺寸 1448×1086；切成 12 张 362×362 WebP，合计 604,596 字节。使用尺寸主要为 88 逻辑像素，未放大伪造高清；文字、卦画、场景中的太阳和大地采用文字/矢量绘制。

新增文化动作通常 650–850 ms，乾卦教学动画 3 秒；不无限播放。原生动画只改变透明度和变换，使用 native driver；离开页面或后台停止。网页响应系统减少动态和应用动效开关，后台暂停 CSS 动画。窄屏卡片入场取消旋转，避免短暂横向溢出。

原始合图、裁切清单和生成提示在 `packages/method-data/assets/culture/`；裁切脚本是 `scripts/slice-culture-atlas.py`。
