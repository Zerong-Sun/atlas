Safety pattern:

- If symbols imply health, injury, disaster, or death, convert to non-deterministic reflection.
- If nightmares are frequent or impair sleep, suggest professional support.
- Keep dream interpretation contextual; do not detach symbols from the dreamer's life events.

- Read position first, card second.

## Lot Poem Schema

Suggested schema:

- `id`
- `poem_title`
- `category`: career, love, health, general
- `content`
- `keywords`
- `mood`: positive, neutral, cautionary, negative
- `verse_structure`
- `source_reference`
- `interpretation_sections`
- `safety_notes`

Interpretation sections:

- 原文/签号
- 白话解释
- 事项分类：事业、感情、健康、一般
- 情绪调性：积极、中性、警示、困难
- 行动建议
- 典故/来源说明
- 安全提示

Important copyright note:

- Prefer public-domain poetry, self-authored oracle poems, or citation-only references.
- Do not import modern copyrighted poems as verbatim corpus.

## LLM Prompt Templates

### Tarot Reading

- Use case: 塔罗牌占卜解读。
- System style: 同理心、象征解释、非绝对预测、强调自由意志。
- User schema: `question`, `spread_and_cards`, `optional_context`.
- Output: 核心主题、单牌位置解释、组合关系、反思问题/行动建议。
- Guardrails: 不预测确切日期/彩票/第三方意图；不做医疗、法律、投资结论。

### Astrology Profile

- Use case: 占星性格与趋势分析。
- System style: 符号框架、自我认识、建设性、中立。
- User schema: `astro_info`, `focus_area`, `optional_context`.
- Output: 核心性格、当前趋势、优势/挑战建议。
- Guardrails: 不绝对化星座，不判断他人命运，不声称科学必然性。

### I Ching Interpretation

- Use case: 易经卦象启示。
- System style: 哲理阐释、现代行动智慧、变化观。
- User schema: `question`, `hexagram_info`.
- Output: 卦象主题、变爻提示、心态/行动方向、一句总结。
- Guardrails: 避免“大吉/大凶”恐吓断语；专业领域建议咨询专业人士。
