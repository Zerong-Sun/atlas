## 塔罗组合解释深化素材

Combination rules:

- 大牌组合指向人生主题，小牌组合落在日常细节。
- 相邻牌形成叙事线，对角/远距牌可看潜在矛盾。
- 同花色连续出现强化对应领域。
- 宫廷牌组合提示角色、人际动态和沟通模式。
- 数字序列变化提示事件节奏。

Position rules:

- 过去位：环境背景与初始条件。
- 现在位：当前能量与主动选择。
- 未来位：潜在趋势，不是必然结果。
- 隐藏位：潜意识动机与未察觉因素。
- 结果位：多因素影响下的可能终点。

Reversal rules:

- 逆位常表示内化、阻滞、延迟、误用或过度。
- 大牌逆位提示根本性课题。
- 小牌逆位提示具体情境阻滞。
- 宫廷逆位提示人格面具或沟通障碍。
- 多张逆位集中出现时关注系统失衡。

Element patterns:

- 火：行动、创意、加速。
- 水：情绪、关系、直觉。
- 风：思考、语言、信息。
- 土：现实、资源、落地。
- 元素相克时，应找动态平衡点。

History features:

- 重复牌型显示周期性课题。
- 高频牌组显示长期关注领域。
- 牌阵结构变化显示认知模式转变。
- 关键词历史可形成个人符号系统。
- 时间对比可观察发展脉络。
