# Atlas 文化文库、插画与 API 验收

日期：2026-10-25。本次范围为全部 24 种就绪占法及其共用的 12 张文化场景图。研究报告先于界面接入编写，随后落到网页、移动端和 AI 解说中。

研究正文见 [24 种占法文化报告](divination-cultures-2026-10-25.md)。该报告由结构化文库生成，包含 27 项资料，逐项区分史实、作者题署、现代实践与证据不足；没有可靠的名人案例时保留空白，不编造故事。为什么使用、文化视角与学习问题是 Atlas 的编辑性解释。

## 六方面验收

1. **需求完整性**：24 种方法全部具备文化摘要、历史案例与人物证据说明；前后学习问题均可离线阅读。12 张共用插画已全部替换。AI 问答、报告解释和失败回退都连接同一文库。
2. **逻辑正确性**：史实不作为预测有效性的证据；古代用途与现代规则分开；来源按当前方法提供；报告文本保持 user 数据身份，不能覆盖 system 要求。既有排盘和随机抽取算法没有在本次文化功能中改动。
3. **边界情况**：无 Key、上游不可用、空问题、无效／原型方法 id、空／截断 JSON、仅推理内容、方法切换与旧请求、来源链接失败均有对应处理。外部资料需要网络，文库正文不需要。
4. **代码质量**：文化数据与提示词在共享包；网页和移动端共用内容及请求门控；不把 API Key 放入仓库。图片为 512×512 WebP，共 667,098 字节，低于既定 700,000 字节预算；来源和逐图最终提示词保存在资产目录。旧 source-sheet 改为预览拼图，不再用来裁图。
5. **测试覆盖**：工作区 182 项测试、桌面协议 3 项测试通过，共 185 项；覆盖新增文库完整性、证据分级、两种提示词、组件来源、失败回退及最终内容判定。双端 TypeScript 检查、网页构建、资源预算、报告一致性和既有语料校验／导入／嵌入 dry-run 均通过。
6. **实际运行结果**：macOS Intel Electron 生产构建离线访问 24 个页面；图片解码、文化正文、来源、390px 窄屏、笔记保存、离线解说回退均通过，renderer error 列表为空。iOS 和 Android Metro／Hermes 导出成功。真实 DeepSeek API 完成 ping、塔罗问答、紫微辨析、周易报告解读；另从桌面 UI 点击文化问题，跑通 renderer → 桌面协议 → 代理 → 服务商全链路。

验证边界：移动端完成类型检查和两平台导出，未在真实 iOS／Android 设备上验证交互。API 结果证明本次配置在测试时可用，不保证服务商未来可用性，也不代表所有其他服务商已实测。来源 id 检查证明引用属于当前文库，不能自动证明模型每一句话都正确；本轮样本另经人工阅读。历史资料链接可能改版，产品保留自写摘要供离线阅读。
