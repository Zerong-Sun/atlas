诸象 Atlas 0.2.0 桌面体验版

Windows 10/11（64 位）：完整解压 Windows-x64.zip 到一个文件夹，双击 ZhuxiangAtlas.exe。不要只取出 exe，其他文件也需要保留。无需安装 Node.js。

macOS 13 或更新版本：完整解压 macOS-universal.zip，将 ZhuxiangAtlas.app 拖到“应用程序”，双击启动。支持 Apple Silicon 与 Intel。此体验版只有本地完整性签名，没有 Apple 开发者签名或公证；macOS 可能阻止首次启动。只有确认文件来自本项目 GitHub Release、校验值一致时，才按系统“隐私与安全性”的提示决定是否允许打开。

基础占卜、经典文本、文化小课与本地记录随应用提供。AI 解读需要联网，在设置中填入自己的服务商 API Key；应用不会附带共享密钥。云端账号/同步依赖另外配置的服务，不是此桌面体验版的交付内容。

记录保存在本机用户目录，不会写回安装文件夹；更新应用时保留。Windows 位于 %APPDATA%\ZhuxiangAtlas，macOS 位于 ~/Library/Application Support/ZhuxiangAtlas。不要删除此目录，除非要清空自己的数据。

版本与下载：https://github.com/Zerong-Sun/atlas/releases/tag/atlas-v0.2.0
Windows 构建需要 Windows 实机进一步验收。文化解释与数据库的已知范围见发布说明。
