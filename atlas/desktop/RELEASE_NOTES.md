# 诸象 Atlas v0.2.2 · 会讲故事的占法体验

本次桌面体验版将近期的文化资料、教学内容和器物图像打包进可离线打开的应用。

## 本次更新

- 24 个占法入口加入简短故事，说明如何提问、如何理解结果；《周易》64 卦和 78 张塔罗牌有各自的情境故事。
- 塔罗牌库提供完整 78 张本地牌图。抽牌、单牌解释、组合解读及历史回放使用实际抽到的牌与具体牌义。
- 三钱起卦显示三枚铜钱的正反面，并按初爻到上爻记录六次结果；窄屏布局已调整。
- 罗盘用有纹样和颜色分区的二十四山盘面显示坐向。可手动选方位；设备没有可靠的绝对方位读数时会提示改用实体指南针。
- 扩充跨文化资料、来源标注与占法说明，并修复罗盘权限取消、传感器超时和角度边界问题。

## 下载与启动

- **Windows 10 / 11，64 位**：下载 `Atlas-v0.2.2-Windows-x64.zip`，完整解压后双击 `ZhuxiangAtlas.exe`。
- **macOS 13 或更新版本，Intel 或 Apple Silicon**：下载 `Atlas-v0.2.2-macOS-universal.zip`，解压后将 `ZhuxiangAtlas.app` 拖到“应用程序”。
- 使用 `SHA256SUMS.txt` 核对 ZIP。GitHub 自动生成的 Source code 不是应用安装包。

AI 解读需要联网，并由用户在设置中填写自己的 API Key；离线基础占法、牌图、文化资料与本地笔记无需云服务。

## 验证与限制

发布工作流执行类型检查、自动测试、网页构建、桌面离线烟雾测试、双平台打包和校验。macOS 包使用本地完整性签名，未获 Apple Developer ID 公证；Windows 包尚无发行者签名。Windows 实机安装和磁传感器精度仍需设备验收。本次发布不更新暂停的 Vercel 网页，也不发布手机商店安装包。
